
# Rock Paper Scissors

This is a simple Rock Paper Scissors game developed in C++. I created this project to practice programming logic and improve my C++ skills.

## About the Game

In this game, the player competes against the computer by choosing between Rock, Paper, and Scissors.

The computer also makes a choice, and the game compares both choices to determine the winner.

## Game Rules

- **Rock** beats Scissors.
- **Paper** beats Rock.
- **Scissors** beats Paper.
- If both choose the same option, it's a tie.
